# ScrollShot — 产品说明

## 一句话定位

**把你这台 Mac 的"手感"打包带走，一键迁移到任何一台新 Mac，让你立刻像在用自家电脑。**

不是搬家、不是备份——是把你**亲手调出来的使用习惯**(快捷键、键盘重映射、触控板/程序坞/访达偏好、截图习惯……)做成一个轻量、可移植的「习惯档案」，在新机上一键复现。

---

## 为什么不是「迁移助理」

苹果自带的**迁移助理**是"全量搬家":把旧机的 App、文件、账号整个拷过来——又重又慢，把旧机的垃圾也一起带过去，还要两台机器同时在场。

ScrollShot 的「习惯迁移」走相反的路:

| | 迁移助理 | ScrollShot 习惯迁移 |
|---|---|---|
| 搬什么 | App + 文件 + 账号(全量) | 只搬你**改过的手感/偏好** |
| 体积 | 几十~几百 GB | 一个几 KB 的 JSON 档案 |
| 干净度 | 把旧机垃圾带过去 | **干净起步**，只带习惯 |
| 适用 | 换机全盘迁移 | 新机干净装、**公司机不让全量迁**、多台 Mac 保持一致 |

**核心理念:只迁移你"偏离系统默认"的那些项**——你没动过的设置在新机上本来就是默认值，无需迁移。所以档案天然精简,装上就是"你的手感"，不是一坨配置。

---

## 它能迁移什么(分层)

| 层 | 内容 | 怎么做 | 状态 |
|---|---|---|---|
| **A 系统手感** | 键盘重复速率、触控板速度/轻点、自然滚动、程序坞(大小/位置/自动隐藏/触发角)、访达(扩展名/路径栏/默认视图)、截图位置与格式 | `defaults`(CFPreferences 跨域读写，无需完全磁盘访问) | ✅ 引擎已通 |
| **B 键盘/输入** | ScrollShot 的键盘重映射规则(如右⌘+hjkl→方向键)、修饰键互换 | 本 App 的 defaults / `hidutil` | ✅ 开关已通，规则待持久化 |
| **C 默认应用/启动项** | 默认浏览器、文件类型关联、开机启动项 | `duti` / LaunchServices / 登录项 | 规划中 |
| **D 开发环境** | dotfiles(.zshrc/.gitconfig)、Homebrew 清单 | 拷文件 + `brew bundle` | 规划中 |
| **E 不做(诚实边界)** | 各 App 内部设置(千差万别/沙箱)、浏览器书签扩展、**凭据密码** | —— | **绝不自动迁移凭据** |

> 诚实声明:"一键迁移**所有**习惯"是方向，但 E 层在工程上做不到自动化(App 各存各的、沙箱、凭据安全)。我们的原则是 **能自动的自动、不能的清单式引导**，绝不承诺做不到的事。

---

## 安全红线

- **导入默认干跑**:逐项预览「现值 → 档案值」，看清楚每一项会改什么。
- **勾选才应用**:确认后才落盘，支持逐项勾选/跳过，绝不偷偷改系统。
- **绝不碰凭据**:密码、密钥、Token 一律不进档案。
- **可还原**:应用后按需重启 Dock/Finder 生效；需注销/重启的项明确提示。

---

## 现有能力(都是"习惯"的一部分，迁移时一并带走)

ScrollShot 本身就是一套 Mac 使用习惯,这些能力既是日常工具,也是被迁移的对象:

- **截图 / 长截图**:全局快捷键框选，滚动长截图，标注(箭头/矩形/文字/马赛克)。**保存位置可自定义**(默认桌面)。
- **磁盘清理**:扫描大文件、安全分类、只移到废纸篓——新机/旧机"干净起步"的配套。
- **键盘重映射**:右⌘ 作为层键，hjkl→方向键(切换器导航 + 普通 App 移动/扩选)。
- **习惯迁移引擎**:导出/预览/应用「习惯档案」(命令行已通，UI 后续)。

## 工程原则(这个产品踩出来的)

- **能本地确定性验证的，先在最快的层验**:迁移引擎在命令行/真实 defaults 上跑通闭环，再上 UI——比起截图覆盖层那种只能真机测的东西，这块能建得有把握。
- **不能本地复现的(如系统级 UI 行为)，靠真机日志逐步逼近，不靠猜。**
- **诚实优先**:做不到的不吹，边界讲清楚。
